Create a full-stack AI web application called “AnimeMorph AI”.

The app should allow users to:

Upload a video up to 10 minutes
Detect people/faces in the video
Convert detected people into animated/anime/cartoon characters
Export the processed animated video
Upload a photo and generate a short animated talking/stylized video from it

Build the app using this stack:

Frontend:

Next.js
React
Tailwind CSS
Modern dark UI
Responsive mobile-friendly design

Backend:

Python FastAPI
REST API architecture
Background processing system

AI/Video Processing:

FFmpeg
OpenCV
MediaPipe for pose and face detection
Stable Diffusion
AnimateDiff
Diffusers
PyTorch

Storage:

Supabase Storage or AWS S3

Authentication:

Email/password auth
JWT authentication

Features:

Drag and drop upload
Upload progress bar
Video preview
Processing status tracker
Queue system for rendering jobs
Download final MP4
